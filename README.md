# ワンオペわんこ亭（仮）

犬のためのドッグフード屋さんで、新人バイトの犬がワンオペでお店を回すマルチタスクゲームです。
先輩が来るまで、注文・盛り付け・提供・片付け・洗い物を同時にさばきます。

> いまは **フェーズ1（最小版）** です。客席2つ・トッピング3種類で、一連の流れだけ遊べます。
> 時間切れのゲームオーバーやクリアはまだありません（フェーズ3で追加）。

## 起動方法

- `index.html` をダブルクリックすると、ブラウザで遊べます（インストール不要）。
- スマホで遊ぶときは横向きにしてください。

## 遊び方（フェーズ1）

1. 客の犬が来ると、吹き出しに注文が出ます（**小・並・大** の盛りと、トッピング）。
2. **どんぶり置き場** から **作業台** へ、どんぶりをドラッグします。
3. **カリカリタンクを長押し** すると、「選択中」のどんぶりにカリカリが入ります。
   - どんぶりの赤い点線が、小・並・大の目安です。
   - 作業台のどんぶりをタップすると、そのどんぶりが「選択中」になります。
4. **トッピング** を、棚からどんぶりへドラッグします。
5. できたどんぶりを、**客席へドラッグ** して出します。
6. 食べ終わった席に残ったどんぶりを、**流しへドラッグ** して片付けます。
7. **食洗機の「洗浄開始」** で、流しのどんぶりを洗います。
8. 洗い上がったら、**食洗機をタップ** して置き場へ戻すか、食洗機から作業台へ直接ドラッグします。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体（スクリプトの読み込み順もここ） |
| `css/style.css` | 見た目・配置 |
| `js/config.js` | **調整用の数値（難易度・時間・トッピングなど）はすべてここ** |
| `js/game.js` | ゲームのルールと状態 |
| `js/view.js` | プレイ画面の表示 |
| `js/input.js` | ドラッグ・タップ・長押しの処理 |
| `js/scenes.js` | 画面の切り替え |
| `js/main.js` | 起動処理 |
| `js/assets.js` / `js/sound.js` / `js/storage.js` | 画像・音・記録の受け口（後で作り込む） |
| `SPEC.md` | 仕様書 |
