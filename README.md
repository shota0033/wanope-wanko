# わんオペわんこ亭

犬のためのドッグフード屋さんで、新人バイトの犬がワンオペでお店を回すマルチタスクゲームです。
先輩が来るまで、注文・盛り付け・提供・片付け・洗い物・下処理を同時にさばきます。

## 起動方法

- `index.html` をダブルクリックすると、ブラウザで遊べます（インストール不要）。
- 公開版：https://shota0033.github.io/wanope-wanko/
- スマホで遊ぶときは横向きにしてください。
- スマホでは「ホーム画面に追加」すると、アプリのように全画面（アドレスバーなし）で起動できます。
  - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
  - Android（Chrome）：右上のメニュー →「ホーム画面に追加」

## 遊び方

### レベル

- タイトル画面で **Lv.1〜Lv.11** から選びます。最初から全部のレベルを選べます。
- 操作はどのレベルも同じで、客の来やすさ・席数・ライフ・どんぶりの数などの数値だけが変わります（詳しくは `LEVELS.md`）。
- 各ボタンには、そのレベルの最高提供数と、クリアしたことがあれば 🏅 が出ます。

### 目的

- 画面上の「先輩が来るまで」のバーが右端に届いたらクリアです。
- 次のトラブルがライフの数（レベルによって4〜2回）だけ起きるとゲームオーバーです。
  - **提供遅れ**：客の待てる時間（吹き出しのバー）が切れて、客が怒って帰った
  - **提供間違い**：注文と違うどんぶりを出した
  - **どんぶりを割った**：流しが満杯なのに、さらにどんぶりを置こうとした
  - **行列の客が帰った**：満席の間、店の外（画面には出ない）で待っていた客が、入れずに帰った

### 料理を出す

1. 客の犬が来ると、吹き出しに注文が出ます（**小・並・大** の盛りと、トッピング）。
2. **どんぶり置き場** から **作業台** へ、どんぶりをドラッグします。
3. **カリカリタンクを長押し** すると、「選択中」のどんぶりにカリカリが入ります。
   - どんぶりの赤い点線が、小・並・大の区切りです。線と線のあいだに入っていれば、その盛りになります（一番下の線より少ないと「カリカリなし」）。
   - 作業台のどんぶりをタップすると、そのどんぶりが「選択中」になります。
   - タンクのカリカリには限りがあります（上限はレベルによって60〜40単位。注いだ量に応じて減ります）。
     減ってきたら、タンクの下の **カリカリの袋をタンクへドラッグ** すると +15単位 補充できます。
4. **トッピング** を、棚からどんぶりへドラッグします。
5. できたどんぶりを、**客席へドラッグ** して出します。

### 片付けと洗い物

1. 食べ終わった席に残ったどんぶりを、**流しへドラッグ** します（片付けるまで次の客は座れません）。
2. **食洗機の「洗浄開始」** で、流しのどんぶりをまとめて洗います（容量と時間はレベルによって 7個・40秒〜5個・50秒）。
3. 洗い上がったら、緑の **「取り出す」ボタン** で置き場へ戻します。
   - 食洗機から置き場や作業台へ、1個ずつドラッグすることもできます。
   - 洗い上がったどんぶりを出すまで、次の洗浄はできません。
4. **手洗い**：流しを **タップしてこする** と、1個ずつ洗えます（20回で1個、洗い終わると自動で置き場へ）。
   - 食洗機が動いている間でも使えます。
   - 速すぎるタップは数えないので、リズムよくこすってください（1個に最短10秒）。

### トッピングの補充（下処理）

- トッピングの容器の右上の数字が残りの量です。0 になると使えません。
- **冷蔵庫をタップ** すると食材の一覧が開きます。食材の印で下処理の方法がわかります。
  - 🔪 **切る**：**まな板へドラッグ** して、まな板を **10回タップ**。
  - ♨️ **茹でる**：**鍋へドラッグ** して入れ（違う種類なら3種類まで）、**鍋をタップで点火**。茹で時間は入れた種類数とレベルで決まります（Lv.6〜10 なら1種類20秒・2種類25秒・3種類30秒）。ゲージが緑の範囲に入ったら **鍋をタップ** して取り出します。遅れると煮すぎて全部無駄になります。
- 下処理が終わると、容器に5人前が補充されます。

### 作り直し

- 作業台のどんぶりを **ゴミ箱へドラッグ** すると、中身を捨てて流しへ送ります（流しが満杯だと割れます）。
- どんぶりの上のトッピングは、**棚へドラッグすると容器に戻せます**。ゴミ箱へドラッグすると、そのトッピングだけ捨てられます。
- まな板や鍋の食材も、ゴミ箱へドラッグすれば捨てられます。

### 中断するとき

- 上のバーの右端の「⏸ 中断」で一時停止できます。つづける・最初からやり直す・タイトル（レベル選択）へ を選べます。
- アプリを切り替えたときも、自動で一時停止します。

## 更新を公開するとき

1. `sh bump-version.sh 番号` で版番号を1つ上げる（例：今が ver.2 なら `sh bump-version.sh 3`）。
   - 読み込むファイルの URL に `?v=番号` が付き、スマホなどで新旧のファイルが混ざらなくなります。
2. コミットして GitHub に送る。1〜2分で公開ページに反映されます。
   - 公開のリンク（https://shota0033.github.io/wanope-wanko/）は変わりません。
   - スマホでは、反映後も最大10分ほど古い版が出ることがあります。タイトル画面の右下の版番号で確認できます。

## 調整・カスタマイズ

- レベル・時間・トッピングなどの数値は、すべて `js/config.js` にあります。時間はすべて実際の秒で書いています。
- 画像の差し替え方は `ASSETS.md` を見てください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体（スクリプトの読み込み順もここ） |
| `css/style.css` | 見た目・配置 |
| `js/config.js` | **調整用の数値（レベル・時間・トッピング・文章など）はすべてここ** |
| `js/game.js` | ゲームのルールと状態 |
| `js/view.js` | プレイ画面の表示 |
| `js/scenes.js` | 画面の切り替え（タイトル（レベル選択）・導入・プレイ・結果） |
| `js/input.js` | ドラッグ・タップ・長押しの処理 |
| `js/assets.js` | 画像の読み込みと差し替え |
| `js/storage.js` | 記録の保存（レベルごとのクリア回数・最高提供数） |
| `js/sound.js` | 効果音・BGMの受け口（今は何も鳴らない） |
| `js/main.js` | 起動処理 |
| `SPEC.md` | 仕様書 |
| `ASSETS.md` | 画像素材の一覧 |
| `DEVLOG.md` | 開発の記録（流れ・決めたこと・今の数値） |
